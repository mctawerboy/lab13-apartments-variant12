# Учет квартир (Вариант 12)

Desktop-приложение на Python (Tkinter) для учета квартир, хранения данных в SQLite и визуализации распределения по площадям и количеству жильцов.

## Функциональность
- операции (создание, чтение, обновление, удаление)
- Импорт/Экспорт данных в JSON
- Поиск и переход к записям
- Визуализация характеристик (Matplotlib)

## Запуск

### Вариант 1: Через терминал
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите приложение: `python main.py`

### Вариант 2: Через PyCharm
1. Откройте проект в PyCharm
2. Откройте терминал внизу 
3. Установите библиотеку: `pip install matplotlib`
4. Нажмите правой кнопкой на `main.py` → **Run 'main'**
